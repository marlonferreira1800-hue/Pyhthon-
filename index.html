class Vehicle:
    def __init__(self, model: str, rate: float) -> None:
        self.model = model
        self._rate = rate

    def rental_total(self, days: int) -> float:
        return round(self._rate * days, 2)

class ExecutiveCar(Vehicle):
    def rental_total(self, days: int) -> float:
        return round(super().rental_total(days) * 0.95, 2)

Pedagogical Approach

The “Reverse Engineering” Methodology

Inspired directly by Fernando Feltrin’s teaching philosophy: instead of memorizing isolated definitions in a vacuum, you start with complete working code and dissect every single token.

01

See Working Code First

Every chapter opens with a self-contained, runnable Python script so you observe real inputs, memory state, and outputs before tackling abstract theory.

02

Dissect Line by Line

Follow Python’s lexical scan top-to-bottom and left-to-right. Understand why each quote, parenthesis, indentation block, and method call behaves the way it does.

03

Modern Python 3.10+ Notes

Faithful to the book’s sequence while clarifying modern Python behavior: keyword.kwlist (35 keywords), is vs ==, *args as tuple, match/case, and safe finally blocks.

04

Practice & Verify with pytest

Apply each module through Basic, Intermediate, and Challenge exercises, compare against reference solutions, and validate everything automatically with pytest.
